Frequently Asked Questions

Everything you need to know about BloomPlayer.

The basics
BloomPlayer is a web app for children to watch YouTube without controls (no rewind, no skip). A parent sets it up, locks it, and hands it to the child.
Built by a mom to help prevent "stimming" behavior in children with autism, where the rewind button reinforces repetitive loops. We remove controls so the child can simply enjoy the content.
Watching & Reporting
If you encounter a broken video, please email us directly at hello@bloomplayer.com. Include the video title and a link to a replacement if you have one!
Parent PIN & Security
You set your 4-digit PIN during the initial setup flow. If you ever need to change it, long-press the BloomPlayer logo on the home screen to access settings.
